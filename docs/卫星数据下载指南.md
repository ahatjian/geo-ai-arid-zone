# 🛰️ 卫星遥感数据下载指南

本指南提供多个**国内可访问**的卫星数据下载源，方便你获取西北干旱区影像数据。

---

## 一、国内数据源（推荐，速度快）

### 1. 地理空间数据云 (gscloud.cn) ⭐ 推荐
**网址**: https://www.gscloud.cn/

**数据类型**:
- Landsat-8/9 (美国陆地卫星，30m分辨率，免费)
- Sentinel-2 (欧空局哨兵卫星，10m分辨率，免费)
- 高分一号/二号/六号 (中国高分辨率卫星)
- MODIS (250m-1km分辨率，免费)

**优点**:
- ✅ 国内服务器，下载速度快
- ✅ 支持中文界面
- ✅ 注册简单（手机号即可）
- ✅ 数据全、更新及时

**下载步骤**:
1. 访问 https://www.gscloud.cn/ 注册账号
2. 点击「高级检索」→「卫星影像」
3. 设置研究区（可上传shapefile或手绘边界）
4. 选择数据源：Landsat-8 OLI 或 Sentinel-2 MSI
5. 设置时间范围（如 2024-06-01 到 2024-09-30）
6. 筛选云量 < 20%
7. 点击检索 → 选择影像 → 下载

**数据格式**: GeoTIFF (.tif)，可直接在ENVI/ArcGIS/QGIS中打开

## 二、国际数据源（数据最全）

### 4. USGS Earth Explorer ⭐ 国际最常用
**网址**: https://earthexplorer.usgs.gov/

**数据类型**:
- Landsat 全系列 (1-9, 1972至今)
- Sentinel-2 (2015至今)
- MODIS (2000至今)
- ASTER (热红外)
- DEM (SRTM, ASTER GDEM)

**优点**:
- ✅ 数据最全、历史最长
- ✅ 完全免费
- ✅ 无需科学上网（国内可访问，但速度一般）

**下载步骤**:
1. 访问 https://earthexplorer.usgs.gov/ 注册账号
2. 登录后点击「Search Criteria」
3. 设置研究区（Address/Coordinates/Shapefile）
4. 点击「Data Sets」→ 选择 Landsat → Landsat 8-9 OLI/TIRS C2 L2
5. 点击「Additional Criteria」→ 设置云量 Cloud Cover < 20
6. 点击「Results」查看搜索结果
7. 选中影像 → 点击下载图标 → 选择 Level-2 GeoTIFF 下载

**提示**: 如果下载慢，可以使用迅雷等下载工具加速

## 五、数据导入本应用

下载的 GeoTIFF 文件可以直接导入本应用分析：

1. 在应用左侧选择 **「📁 本地GeoTIFF文件」**
2. 点击「上传GeoTIFF文件」
3. 选择下载的 `.tif` 文件
4. 应用会自动显示影像并提取文件信息

### 多波段影像说明
- Sentinel-2: 通常有 10+ 个波段（B2-B12）
- Landsat-8: 通常有 7+ 个波段（B1-B7）
- 应用会自动识别波段数并显示

4. Data Sets → Landsat → Collection 2 Level-2

6. 下载 GeoTIFF 产品

## 七、常见问题

**Q: 下载的数据打不开？**
A: 确保下载的是 GeoTIFF 格式（.tif），不是 JP2 或 HDF。如果是 Landsat 的 .tar.gz 压缩包，需要先解压。

**Q: 数据量太大？**
A: 一景 Landsat-8 约 1GB，Sentinel-2 约 700MB。如果只需要一个小区域，可以在下载后用 QGIS/ArcGIS 裁剪（Clip）。

**Q: 如何批量下载？**
A: 地理空间数据云支持批量下载。USGS Earth Explorer 可以使用 Python 脚本批量下载（使用 landsatxplore 库）。

**Q: 没有科学上网怎么办？**
A: 优先使用地理空间数据云（gscloud.cn），国内服务器，完全不需要翻墙。

## 八、Python 批量下载脚本

如果你需要批量下载，可以使用 Python 脚本：

```python
# 安装工具
pip install landsatxplore sentinelhub

# Landsat 批量下载示例
from landsatxplore.api import API
from landsatxplore.earthexplorer import EarthExplorer

api = API('你的用户名', '你的密码')
scenes = api.search(
    dataset='landsat_ot_c2_l2',
    latitude=37.5,
    longitude=96.0,
    start_date='2024-06-01',
    end_date='2024-09-30',
    max_cloud_cover=20
)

print(f"找到 {len(scenes)} 景影像")
for scene in scenes:
    print(scene['display_id'])
```
